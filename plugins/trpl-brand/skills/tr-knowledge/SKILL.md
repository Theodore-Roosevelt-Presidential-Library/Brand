# Theodore Roosevelt orientation

Read `guide/tr-essentials.md` and `guide/brand-foundation.md` at the plugin root.

## What this skill is for

Giving people enough context to brief, plan and write well: the shape of
T.R.'s life, the themes the Library leads with, the language to use and the
traps to avoid.

## What it is not

A source. Nothing you say from memory or from this kit counts as a source for
anything published. The rule (two independent sources per claim) is in
`guide/accuracy-and-approvals.md`.

## How to answer

1. **Orientation questions** ("what should I know before writing about the
   Badlands years?", "how does the Library talk about conservation?"): answer
   from the guide pages, in plain language. Mark any specific date, number or
   name you give as "to verify."
2. **Specific factual questions** ("when did he buy the Elkhorn?", "how many
   national monuments?", "is this quote real?"): run
   `trpl-brand:historian-handoff`. Don't answer from memory first.
3. **Framing questions on hard subjects** (race, Indigenous peoples, empire,
   Brownsville, eugenics): give the Library's approach (humanize, don't
   lionize; describe accurately; present real disagreement) and hand off to
   HistorianPanel's scholarly-debate or review-lenses skills for substance.
   Content about Indigenous peoples always needs the Library's review.
4. **"Give me a quote about X":** hand off. Never supply a T.R. quotation from
   memory.

## Point people to

- trlibrary.com/tr (reading, not a citable source)
- The Theodore Roosevelt Center Digital Library, the Library of Congress
  Theodore Roosevelt Papers, and NPS sites (links in `guide/tr-essentials.md`)
- `trpl-brand:find-tr-media` for images and film
