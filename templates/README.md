# Templates

Editable, reusable templates organized by channel. Templates here are the starting point for new TRPL designs — not finished examples.

## Subfolders

| Folder | Contents |
|---|---|
| `social-media/` | Canva template links or export files for recurring social formats |
| `print/` | InDesign, Canva, or PDF templates for print materials |
| `email/` | HTML email templates and header/footer assets |

## How to Document a Template

Include a `README.md` in each subfolder listing available templates with:
- Template name and brief description
- Canva link (if applicable) or file name
- Intended use / dimensions
- Last updated date

## Canva Templates

For Canva templates, save the shareable Canva link in a `canva-links.md` file within the relevant subfolder. Do not export and commit large Canva files unless a static reference copy is specifically needed.
