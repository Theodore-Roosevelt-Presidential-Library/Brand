The Story Guide (Part Two: T.R.'s Story, starting on page 148 of `../../../brand-guidelines/TRPLStoryGuide_CaseInt_hires.pdf`) provides context for the six narrative chapters: Child, Young Professional, Lawman, Colonel, President, Lost Hero.
