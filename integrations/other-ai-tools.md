# Other AI tools

The whole guide is published as plain text so any tool can use it.

## Any chat assistant (ChatGPT, Gemini, Copilot, and others)

Give it the full guide, as a link or an upload:
[`https://brand.labs.trlibrary.com/llms-full.txt`](https://brand.labs.trlibrary.com/llms-full.txt).

For a project, custom GPT, Gem or agent, paste this as its instructions:

> You write and design for the Theodore Roosevelt Presidential Library in
> Medora, North Dakota. Follow the brand guide at
> https://brand.labs.trlibrary.com/llms-full.txt exactly. Voice: friendly,
> plainspoken, specific, story-first, nonpartisan. Use "participants,"
> "Trustees," "Benefactors," "T.R." (never "Teddy"), "buttes." Never write a
> Theodore Roosevelt quotation from memory; mark it for verification. Mark every
> historical claim you are not certain of with [VERIFY]. Never generate images
> of people, the Library or any building.

**These tools don't verify history.** Every historical claim still needs two
independent sources before publishing; see
[Accuracy and approvals](../plugins/trpl-brand/guide/accuracy-and-approvals.md).

## Coding assistants and websites

- CSS variables: [`tokens.css`](https://brand.labs.trlibrary.com/tokens/tokens.css)
- Tailwind: [`tailwind.preset.js`](https://brand.labs.trlibrary.com/tokens/tailwind.preset.js)
- Web fonts (Library sites only, licensed): [`fonts.css`](https://brand.labs.trlibrary.com/assets/fonts/web/fonts.css)
- Repositories can point their assistant at this repo's [CLAUDE.md](../CLAUDE.md)
  or [AGENTS.md](../AGENTS.md).

## Figma and design tools

[`tokens.json`](https://brand.labs.trlibrary.com/tokens/tokens.json) uses the
W3C Design Tokens format, which Tokens Studio for Figma and similar plugins can
import. Logos: [Logos and marks](../assets/README.md).
