# Brand Guidelines

This folder contains the core documentation for TRPL's visual and verbal identity system.

| File | Contents |
|---|---|
| [brand-overview.md](./brand-overview.md) | Mission, voice, audience, content hierarchy, institutional terminology |
| [color-system.md](./color-system.md) | Color palette, hex/RGB/CMYK values, usage rules, accessibility |
| [typography.md](./typography.md) | Type hierarchy, font specs, usage rules, web font guidance |
| [voice-and-tone.md](./voice-and-tone.md) | Writing principles, tone by channel, terminology reference |
| [usage-guidelines.md](./usage-guidelines.md) | Logo dos/don'ts, color rules, photography guidance, co-branding policy |

## Source

All values in these documents are sourced from the official *Brand Identity System & Guidelines* (Local Projects, May 27, 2020), which is included in this folder as `200527_TRPL_BrandGuidelines.pdf`.

One remaining open item: **ITC Clearface web font licensing** — the MyFonts web font kit does not include Clearface web fonts. Confirm web embedding rights with the ITC EULA (see `assets/fonts/clearface/`) before deploying to trlibrary.com.
