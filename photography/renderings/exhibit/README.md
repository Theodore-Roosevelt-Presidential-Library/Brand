# Exhibit Renderings

Interior exhibit and gallery design renderings for the Theodore Roosevelt Presidential Library, created by **Local Projects** (New York), the interpretive design firm for the permanent collection.

## Subfolders

### `press-approved/`
Seven named gallery renders approved for press and marketing use. These are the go-to files for external communications, media kits, and partner presentations.

| File | Gallery / Space |
|---|---|
| `trpl_exhibit_cuba-prebattle.jpg` | Cuba pre-battle gallery |
| `trpl_exhibit_into-the-arena.jpg` | "Into the Arena" entry experience |
| `trpl_exhibit_narrative-gallery.jpg` | Main narrative gallery |
| `trpl_exhibit_natural-history.png` | Natural history (RMNH) gallery |
| `trpl_exhibit_sagamore.jpg` | Sagamore Hill gallery |
| `trpl_exhibit_storytelling-campfire.png` | Storytelling campfire orientation |
| `trpl_exhibit_white-house.jpg` | White House gallery |

### `full-set-local-projects/`
The complete numbered set of 70 exhibit renderings from Local Projects (files 01–69 plus supplemental). These are for internal reference, content strategy, and design work — not blanket press use. Confirm with Local Projects before publishing individual numbered renders externally.

## Copyright and Usage

All exhibit renderings are the work of **Local Projects**. External use requires Local Projects' approval. The press-approved set in `press-approved/` has been cleared for appropriate media and partner use; always verify before use in new contexts. Credit line when required: *Rendering: Local Projects.*

## About Local Projects

Local Projects is the interpretive design firm responsible for the TRPL's permanent exhibits and the exhibit rendering set. They also created the TRPL Brand Identity System & Guidelines in 2020, which established the visual identity in use today.
