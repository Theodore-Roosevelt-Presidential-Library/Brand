# Logos

All approved TRPL logo files. Never recreate or redraw from scratch — always use files from this folder.

Source: *Brand Identity System & Guidelines* (Local Projects, May 27, 2020)

## Logo Marks

TRPL has two primary marks:

1. **Wordmark** — The typographic logo pairing Dharma Gothic Bold with ITC Clearface
2. **Stamp Mark** — A circular stamp/seal design used across applications
3. **TR Initials Mark** — Two variants (V1, V2) of a TR monogram stamp

## Usage Rules

- **Minimum size:** 0.75" height for the primary wordmark
- **Clear space:** 2× the width of the "T" crossbar in "Theodore" on all sides
- Never stretch, condense, rotate, or distort any logo file
- Use RGB files for screen; CMYK/EPS files for print
- Do not place the wordmark on a busy background without a clear zone
- Do not apply effects (shadows, glows, outlines) to any logo file
