# Assets

Supporting graphic elements that are used across TRPL designs but are not logos or photography.

## Subfolders

| Folder | Contents |
|---|---|
| `icons/` | Custom TRPL iconography — UI icons, wayfinding icons, exhibit icons |
| `patterns/` | Brand patterns for backgrounds, dividers, and decorative use |
| `textures/` | Texture overlays and surface treatments |

## Icons

TRPL has an iconography system documented in the brand guidelines. Icons should be:
- Provided in SVG format
- Named descriptively: `icon_[subject]_[style].[ext]` (e.g., `icon_conservation_outline.svg`)
- Consistent in stroke weight and visual style

## Naming Convention

`[type]_[descriptor]_[variant].[ext]`

Examples:
- `icon_bison_outline.svg`
- `icon_conservation_filled.svg`
- `pattern_badlands-stripe_horizontal.svg`
- `texture_paper_light.png`
