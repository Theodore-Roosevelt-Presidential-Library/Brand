# Instructions for AI agents

This repository is the brand kit of the Theodore Roosevelt Presidential Library.
If you are an AI agent working here or using this kit for Library work:

1. Read [CLAUDE.md](CLAUDE.md). It applies to any agent, not only Claude.
2. The brand guide is in [`plugins/trpl-brand/guide/`](plugins/trpl-brand/guide/README.md).
   Read the relevant page before writing, designing or reviewing.
3. The skills in [`plugins/trpl-brand/skills/`](plugins/trpl-brand/skills/) are
   plain-markdown procedures. Follow them even if your tool doesn't load skills.
4. Never treat your own output as a source for historical facts. Two independent
   sources per claim; see [Accuracy and approvals](plugins/trpl-brand/guide/accuracy-and-approvals.md).
5. Never push to `main`. Open a pull request.
6. This repository is public. No staff names, internal links, credentials or
   unapproved figures.
