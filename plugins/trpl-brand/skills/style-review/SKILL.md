# Style review

Read `guide/editorial-style-guide.md`, `guide/voice-and-tone.md` and
`guide/channels.md` at the plugin root. They are the rules; this skill is the
procedure. If anything here disagrees with the guide, the guide wins.

This checks **wording and voice**, not historical fact. Facts go to
`trpl-brand:historian-handoff`.

## Procedure

1. **Read once for voice.** Friendly, plain, specific, story-first,
   nonpartisan, warm with a serious mission. Note the two or three biggest
   voice issues, if any.
2. **Terminology pass.** Go through the editorial guide's quick-reference table
   and every Always/Never rule. Record each hit with its location.
3. **Patterns that need judgment:**
   - Gratitude repeated, stacked or vague
   - Throat-clearing and filler
   - Leading with a negative
   - Institution-first openings
   - Current or future years in evergreen copy; restated hours
   - Counting items to introduce links
   - Anything in quotation marks attributed to T.R. (flag for verification; never "fix" the wording yourself)
   - The four Values presented as a T.R. quote
   - Names of current or recent political figures (flag for review)
   - Sustainability, financial or attendance figures (flag for review)
4. **Channel rules** for the channel in question (visit link, single link on
   press posts, From name, and so on).
5. **Mark facts for the panel.** Any hit that is also a factual claim (for
   example "San Juan Hill" with a date) goes on the hand-off list.

## Output

A table: location · current wording · suggested wording · rule (with the guide
section). Then:

- one line with the count by rule level (Never / Always / Prefer)
- the hand-off list for HistorianPanel, if any
- reviews needed before publishing, if any

Explain each change in a few words so the writer learns the rule. Rewrite the
whole piece only if asked.

## When the guide is silent

Don't invent a rule. Say the guide doesn't cover it, recommend the most
consistent choice, and offer `trpl-brand:update-style-guide` to settle it.
