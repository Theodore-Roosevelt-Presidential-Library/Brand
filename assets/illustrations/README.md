# TRPL Illustrations

Brand illustration assets including sticker series and decorative marks.

## Sticker Series (`stickers/`)

Four themed sticker designs, each available in multiple formats. These are approved TRPL branded illustrations — not photographic assets.

| Theme | Description | Files |
|---|---|---|
| `conservation/` | Conservation theme sticker | AI, EPS, PDF, SVG, PNG |
| `president-campaign/` | Presidential campaign theme sticker | AI, EPS, PDF, SVG, PNG |
| `rancher/` | Rancher / Badlands theme sticker | AI, EPS, PDF, SVG, PNG |
| `rough-rider/` | Rough Rider theme sticker | AI, EPS, PDF, SVG, PNG |

Each theme folder contains:
- `.ai` — Source file (Adobe Illustrator)
- `.eps` — Print-ready vector (CMYK)
- `.pdf` — Print-ready PDF
- `.svg` — Web/screen vector
- `-01.png` — Raster preview

## Usage Notes

- Always use source vector files (AI, EPS, SVG) for production — never upscale from PNG
- Stickers should not be used on backgrounds that conflict with the brand's earnest, grounded tone
- Do not apply effects, filters, or color modifications without brand team approval
- These are TRPL original illustrations — do not alter the artwork or use components in isolation
