# Design Examples

Finished, approved design work organized by content type. This folder is the primary training reference for AI-assisted design — it shows how TRPL's brand looks in real-world applications.

When adding examples, include a mix of:
- Strong "hero" examples that represent the brand at its best
- Everyday workhorse designs (social posts, email headers, event graphics)
- Edge cases showing how the brand adapts to challenging formats

## Naming Convention

`trpl_[channel]_[type]_[descriptor]_[date-or-version].[ext]`

Examples:
- `trpl_social_instagram_square_opening-countdown_2026-05.jpg`
- `trpl_print_brochure_visitor-guide_2026.pdf`
- `trpl_email_full_grand-opening-announcement_v1.png`
- `trpl_digital_web-banner_homepage-hero_1440w.jpg`

## Annotation

When adding a particularly strong or instructive example, add a companion `.md` file with the same base name to explain the design decisions:

`trpl_social_instagram_square_opening-countdown_2026-05.md`

```md
# Opening Countdown Post — Instagram Square

**Why this works:** Strong typographic hierarchy leads with the countdown number.
Brand colors used at full saturation against the Badlands photograph. CTA in caption
drives to trlibrary.com/visit.

**Channel:** Instagram
**Dimensions:** 1080x1080px
**Date:** May 2026
```
